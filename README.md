# Ao Soccer — نموذج أولي ثلاثي الأبعاد (Godot 4)

لعبة كرة قدم للموبايل مستوحاة من **أسلوب** أنمي *Ao Ashi*: كرة قدم تكتيكية تعتمد على
**قراءة الملعب والتمركز** بدل القوى الخارقة. الشخصيات والفرق والأسماء كلها أصلية
(لا نستخدم أي محتوى محمي من العمل الأصلي).

## الميزة الأساسية: رؤية الملعب 👁️
اضغط **VISION**: يتباطأ الوقت، وترتفع الكاميرا لمنظر علوي للملعب كامل، وتظهر كل خطوط التمرير:

- 🟢 **أخضر:** الممر مفتوح.
- 🟡 **أصفر:** الممر خطِر.
- 🔴 **أحمر:** الممر مقطوع.
- **BEST:** أفضل خيار تمرير.

**المسْ أي زميل** لتمرّر له مباشرة. وإذا كانت الكرة مع الخصم، تشوف خيارات تمريره
(**DANGER**) عشان تعرف أي ممر لازم تقطعه. الطاقة تنقص أثناء الاستخدام وتتعبأ مع الوقت.

## التحكم
| الموبايل | الكيبورد | الوظيفة |
|---|---|---|
| جويستك (يسار الشاشة) | WASD / الأسهم | الحركة |
| PASS | Space / J | تمرير (باتجاه الجويستك). بدون كرة يصير **SWITCH** لتبديل اللاعب |
| SHOOT | K / Enter | تسديد (الجويستك فوق/تحت يحدد زاوية المرمى) |
| VISION | L / Shift | رؤية الملعب |

## المحتوى الحالي
- **ثلاثي الأبعاد بأسلوب أنمي:**
  - لاعبون بتظليل Cel-shading وحدود حبر (inverted hull).
  - شعر أنمي بتسريحات مختلفة، وعيون كبيرة، وأرقام على الظهر.
  - أنيميشن جري وتسديد واحتفال، كله مبني بالكود.
- **ملعب كامل:**
  - خطوط مرسومة بـ shader.
  - مرمى بشبكة.
  - لوحات إعلانية.
  - مدرجات بجمهور متحرك.
  - سماء وظلال.
- **مخرج كاميرا (Camera director):**
  - كاميرا بث تلفزيوني تتابع الكرة.
  - لقطة سينمائية بطيئة خلف المسدد عند كل تسديدة، مع خطوط تركيز مانغا (Focus lines).
  - كاميرا تدور حول المسجّل وهو يحتفل.
  - منظر علوي عند استخدام VISION.
- **اللعب:**
  - مباراة 5 ضد 5 مدتها 3 دقائق.
  - فيزياء كرة فيها ارتفاع: التمريرة تُرفع تلقائياً إذا الممر مقطوع.
  - ذكاء اصطناعي للفريقين، يشمل التمركز والضغط والتمرير والتسديد، وحارس مرمى يقرأ اتجاه التسديدة.
  - تبديل تلقائي للاعب الأقرب.

## التشغيل
1. نزّل [Godot 4.4+](https://godotengine.org/download).
2. افتح `project.godot` واضغط ▶️ (F5). الماوس يحاكي اللمس على الكمبيوتر.

### على الجوال (أندرويد) 📱
مع كل تحديث على `main`، يبني GitHub Actions ملف APK موقّعاً، ويختبره بمحاكاة مباراة كاملة،
ثم ينشره في صفحة **[android-latest](../../releases/tag/android-latest)**.

1. افتح صفحة الـ Release من جوالك، ونزّل `AoSoccer.apk`.
2. افتح الملف واسمح بـ "التثبيت من مصادر غير معروفة" إذا طلبها الجوال.
3. شغّل اللعبة. عدّاد الـ FPS بالزاوية يوضّح سرعة الأداء.

يشتغل على أندرويد 5 وما فوق، بمعمارية ARM 32 و 64 بت.

**التحديثات:** كل بناء يوقَّع بمفتاح مؤقت، فلازم تحذف النسخة القديمة قبل تثبيت الجديدة.
عشان تثبّت التحديثات فوق بعض، أضف مفتاحاً ثابتاً في
`Settings → Secrets and variables → Actions` بهذه الأسماء:
`ANDROID_KEYSTORE_BASE64` و `ANDROID_KEYSTORE_PASSWORD` و `ANDROID_KEY_ALIAS`.

**من محرر Godot مباشرة:** وصّل الجوال بكابل USB، وفعّل وضع المطوّر (USB debugging)،
ثم اضغط زر أندرويد أعلى المحرر (One-click deploy). هذا يحتاج Android SDK و JDK 17،
حسب [دليل Godot](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html).

### اختبار المحاكاة
```bash
godot --headless --path . --fixed-fps 60 -s tests/sim_test.gd
```
يلعب مباراة كاملة بمدخلات عشوائية، ويتأكد من مسار المباراة كله: البداية، والأهداف، ونهاية المباراة، وإعادة التشغيل.

## هيكل المشروع
```
scenes/main.tscn          المشهد الرئيسي (يبني كل شيء بالكود)
scripts/soccer_match.gd   سير المباراة + الذكاء الاصطناعي + التمرير والتسديد + مخرج الكاميرا
scripts/footballer.gd     اللاعب: المنطق على مستوى ثنائي الأبعاد + مزامنة النموذج الثلاثي
scripts/player_model.gd   نموذج اللاعب الأنمي والأنيميشن
scripts/ball.gd           فيزياء الكرة واكتشاف الأهداف + الكرة الثلاثية
scripts/stadium.gd        الملعب والمرمى والمدرجات والإضاءة
scripts/field_vision.gd   ميزة رؤية الملعب (طبقة على الشاشة)
scripts/touch_controls.gd تحكم اللمس المتعدد
scripts/hud.gd            لوحة النتيجة ولقطات القطع وخطوط التركيز
scripts/toon.gd           مواد التظليل الأنمي
shaders/                  toon / outline / pitch / ball / crowd / net
tests/sim_test.gd         اختبار محاكاة headless
```
> المنطق يشتغل على مستوى ثنائي الأبعاد (x, y)، ويتحوّل إلى عالم ثلاثي الأبعاد (x, z) عبر `Config.to_3d`.
> هذا يخلّي الذكاء الاصطناعي والفيزياء بسيطين وسهلين في الاختبار.
